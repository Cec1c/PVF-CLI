# 验收标准

默认测试使用仓库中的合成样本。真实样本须显式设置 `PVFCLI_REAL_PVF_SMOKE`；缺少样本或系统权限而跳过的检查不计作通过。测试日志、性能测量和真实资产证据放在忽略目录。

## 样本与来源

- 合成样本应覆盖 NKPI 与 protected NKPI 的实际分支，包含中文、UTF-16LE、空文件及边界字段。
- 真实样本由使用者显式选择，记录完整 SHA256、大小、格式和条目数。样本与解包内容放 ignored 目录。
- 真实测试通过 `PVFCLI_REAL_PVF_SMOKE` 选择样本；缺少时 `t.Skip`，报告须保留跳过统计。
- 来源测试中的装备、礼包和黑钻模板路径只适用于对应样本。不能为让测试通过而制造不存在的真实条目。

## 只读行为

| 检查 | 要求 |
| --- | --- |
| 列目录 | 文件数、路径、类型、大小可与来源读取器对照；排序和截断规则明确 |
| 文本读取 | type-1/type-3 分开验证，编码与换行可解释；未知类型明确提示 |
| 原始读取 | 字节摘要精确一致；输出不掺日志 |
| 搜索 | 路径/正文语义分开；前缀、大小写、空结果、数量限制和取消均有约定 |
| 导出 | 拒绝 `..`、绝对路径、盘符及链接逃逸，覆盖冲突有明确策略 |
| 错误输入 | 截断、越界、损坏压缩数据、未知格式/类型返回可诊断错误而非 panic |
| 机器输出 | JSON 结构稳定、stderr 独立，批量失败可被脚本判断 |
| 输入不变 | 读取前后核对样本 SHA256 |

## 写回行为

- token round-trip 覆盖整数、float32 位模式、字符串种类、未知类型和异常尾部；可读文本相同不能代替 raw/token 保真。
- 字符串池追加保持旧偏移的规则有测试；同宽池替换应验证所有受影响引用。
- 替换、追加、HASH 和分块重建分别验证，不能把单一模板通过扩展为通用格式支持。
- 写入目标与输入的路径别名、已有输出、权限不足、取消、写入失败和回读失败均保留原文件。
- 独立重开输出核对目录和内容，比较未修改条目的 raw 摘要；必要时与另一独立实现或受控客户端核对，避免仅靠同一个读写器自洽。

## 性能与产物

记录输入规模、条目数、操作、并发数、缓存容量、冷/暖状态、耗时、峰值内存和最终 Go 堆。全档搜索不要通过永久累积所有解码结果实现。

现有 `ScanTextPrefix` 值得复用评估，但整包打开的基础内存仍需测量。Go 可执行文件大小、PVF 文件大小、构建缓存占用和运行时内存分别报告。

## 构建与隔离

基本检查为 `gofmt`、`go test ./... -count=1`、`go vet ./...` 和 `go build -trimpath -o dist/pvf.exe ./cmd/pvf`。Windows的 `BUILD.bat` 提供测试／vet／构建入口。测试范围按变更扩展，不运行来源项目的全套游戏服务端测试。

缓存和输出都放本项目的 ignored 目录。例如在当前 PowerShell 会话中设置项目专用 `GOCACHE`，不修改全局 Go 配置，也不执行 `go clean -cache`。并行读取和缓存实现变更时评估 race 检查。

每次交付分别报告：合成测试、真实 PVF 对照、写回保真、性能、目标平台、原生客户端验收。未运行或条件跳过的部分保留其实际状态。
